# Введение
Мой проект исследует рынок вакансий для аналитиков данных с фокусом на удалённые позиции и прозрачность зарплат. С помощью SQL-запросов я проанализировала, какие роли предлагают самую высокую заработную плату и какие навыки работодатели требуют чаще всего.
Цель: предоставить практические инсайты для профессионалов, желающих повысить квалификацию или перейти в аналитику данных, а также для HR-специалистов, изучающих рынок турда.
# Инструменты
SQL для всей обработки и анализа данных
CSV-датасеты с вакансиями и навыками
# Анализ
Каждый SQL-файл в проекте отвечает на конкретный бизнес-вопрос:
1. top_paying_remote_jobs.sql

Вопрос: Какие 10 удалённых вакансий аналитика данных предлагают самую высокую зарплату?
Фильтрация удалённых позиций с указанной зарплатой (не NULL)
Сортировка по убыванию зарплаты
Ограничение результата 10 вакансиями

2. top_paying_skills.sql

Вопрос: Какие навыки требуются для этих 10 высокооплачиваемых вакансий?
JOIN таблиц вакансий и навыков по ID
Вывод всех навыков, связанных с топ-позициями

3. most_in_demand_skills.sql

Вопрос: Какие 5 навыков наиболее востребованы в целом?
Использование INNER JOIN между вакансиями и навыками
Группировка по названию навыка
Сортировка по убыванию частоты

4. avg_salary_by_skill.sql

Вопрос: Какие навыки коррелируют с самыми высокими средними зарплатами?
Расчёт средней зарплаты для каждого навыка
Исключение вакансий с NULL-значениями зарплаты

5. optimal_skills.sql

Вопрос: Какие навыки оптимальнее всего осваивать?
Баланс между востребованностью и зарплатой
Фильтрация удалённых вакансий с указанной зарплатой
Выделение навыков, которые часто встречаются и хорошо оплачиваются

В ходе работы я закрепила полученные навыки SQL (джойны, агрегатные функции, фильтрация данных, группировка и сортировка)
Также я сделала выводы по реальным данным о рынке труда, например, что самым востребованным навыком остается SQL, Python, Tableu. На основе этих данных отметила для себя на какие навыки нужно обратить особое внимание и углубиться в их изучение.
