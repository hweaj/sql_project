# Introduction
Мой проект исследует рынок вакансий для аналитиков данных с фокусом на удалённые позиции и прозрачность зарплат. С помощью SQL-запросов я проанализировала, какие роли предлагают самую высокую заработную плату и какие навыки работодатели требуют чаще всего.
Цель: предоставить практические инсайты для профессионалов, желающих повысить квалификацию или перейти в аналитику данных, а также для HR-специалистов, изучающих рынок турда.
